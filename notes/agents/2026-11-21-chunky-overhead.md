# Headless tabletop rendering

The official Chunky update endpoint is chunkyupdate.lemaik.de. Use the pinned
manifest and run the core main class directly in the existing Java container.
A parallel camera points down with pitch zero. The initial pitch of minus pi
pointed up even though Chunky successfully generated a PNG, so inspect the
image as well as the exit code. Copy the custom dimension regions into a
temporary overworld-shaped save with level.dat before invoking Chunky.
