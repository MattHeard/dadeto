# Atlas native activation identity import — 2026-10-20

- **Unexpected hurdle:** The completed Pythia replay artifact had 512 native MLP components and token-indexed activations, while the V2 graph accepted only recurrent components and time steps.
- **Diagnosis:** The V1 artifact already records the pinned model/checkpoint, layer, post-GELU hook, neuron index, token position, input sequence, token ID, experiment, run, activation value, and precision. Existing V2 recurrent component IDs and position records must remain byte-for-byte compatible.
- **Chosen fix:** Add canonical V2 `native-neuron` component identities and `token` activation positions. Native component IDs include the kind in their canonical tuple and retain a checkpoint-independent coordinate ID; token position IDs include the component, token kind, and zero-based token index. V2 observations optionally retain `tokenId`, without changing observation identity. The portable graph accepts both recurrent and native/token records. An artifact-backed test constructs the V2 graph, validates it, and round-trips 512 components, 512 positions, and 1,024 repeat observations.
