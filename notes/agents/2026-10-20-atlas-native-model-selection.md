# Atlas native model selection — 2026-10-20

- **Unexpected hurdle:** The previously examined Neuronpedia circuitgpt source has conflicting inference metadata, and this environment has no local model runtime for replay.
- **Diagnosis:** Neuronpedia GPT-2 SAE records are trained features, not native MLP neurons. Local Python has `numpy`, but `torch`, `transformers`, and `safetensors` are absent; the Dadeto package manifest also has no model-inference runtime. A native-model candidate can be selected from publisher metadata, but replay cannot be claimed here.
- **Chosen candidate:** `EleutherAI/pythia-14m`, pinned to Hugging Face revision `94f7c35d5e9f2e9bac8ca839329f505b4d007d5d` (the publisher labels this commit “Upload final model (step 143000)”). Its config identifies `GPTNeoXForCausalLM`, 6 layers, `intermediate_size: 512`, `hidden_act: gelu`, and Transformers 4.40.0. That yields 3,072 architectural native MLP coordinates (6 × 512), distinct from SAE feature IDs. The model is listed under Apache-2.0. Its Safetensors file is 28,143,920 bytes with SHA-256 `116a02532db461f91386a5b20f942ff2c8d4de7341e21b55caafc3d7b25f49a1`.
- **Activation hook:** In Transformers 4.40.0, each GPT-NeoX layer's MLP applies `dense_h_to_4h`, then GELU, then `dense_4h_to_h`. Capture the output of `gpt_neox.layers.{layer}.mlp.dense_h_to_4h` and apply the configured GELU to record the 512 post-activation native MLP units. A component identity should include the pinned model/checkpoint, layer, this named hook, and unit index; token position and input/run belong to activation-position and observation identities.
- **Replay path:** The model config records Transformers 4.40.0. The later replay loop used Transformers 4.45.2 and Tokenizers 0.20.3 to get Python 3.13 ARM64 wheels, with CPU-only PyTorch 2.6.0 and Safetensors 0.5.2; it confirmed the same `dense_h_to_4h -> GELU -> dense_4h_to_h` operation order in the pinned Transformers source and in the run.
- **Local feasibility and limits:** At this selection loop's start, `torch`, `transformers`, and `safetensors` were missing. The subsequent replay Bead installed a temporary pinned runtime and downloaded only the 28,143,920-byte checkpoint. It captured 512 native coordinates and repeated the same activation vector exactly. It did not write to Neuronpedia. Pythia remains an independently published source, not a Neuronpedia-hosted native-neuron record, so registration must preserve that provenance.
- **Next action / cross-loop update:** Bead `dadeto-1z12` has produced the reproducible activation artifact at [notes/agents/pythia-14m-native-activation.json](pythia-14m-native-activation.json). The measurement uses explicit token-position IDs separate from its input/run-specific observations. The canonical V2 position schema is still recurrent-only, so a follow-up must add feed-forward token positions before this artifact can be imported into the identity graph.
