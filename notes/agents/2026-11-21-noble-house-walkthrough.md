# Noble’s House walk-through

The presentation board used low walls that could be stepped over. Raising them
revealed missing connections to the study and common room. The compiler now
checks that every named room can be reached on foot, adds the missing doorways
and keeps the read-only board layout intact. The walk-through uses the same
plan translated 72 blocks south, outside the lab footprint. The ceiling cutaway
render is useful for checking a layout which would be hidden from above.

The household reuses the verified Geyser skin event approach. Set avatar UUIDs
within the spawn consumer and preserve the non-sentinel bootstrap profile.
Verify actual Switch rendering separately from server entity existence.
