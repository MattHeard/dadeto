# Paint blog toy

Added PAIN1 with a dedicated `paint` presenter and text-in/text-out toy entry.
The existing CANV1 presenter produces generated shapes; its behavior stays intact.
Paint uses pointer capture, CSS-to-bitmap coordinate scaling, one active pointer,
and cancellation handling. Color, size, eraser and clear use native controls.
Full screen is a viewport overlay (browser chrome stays visible), with an exit
button and Escape. Canvas dimensions never change on toggle, preserving pixels.
Submitting again or reloading resets the drawing; saving/export is outside scope.

## Auto polling regression from the mobile recording

The user supplied a Chrome recording with Auto enabled. Auto polls every frame
and the output renderer unconditionally removed/recreated the Paint panel,
discarding pointer capture, pixels, tool values and full-screen state. The
presenter-only tests missed this lifecycle interaction.

`test/browser/toys.paint.autoSubmit.test.js` now drives the real Auto polling
registration with queued animation frames and touch pointer events. Before the
fix it failed because the mounted panel changed after a frame. After the fix it
passes, retaining the connected canvas, active stroke, color, size and expanded
panel across frames without clearing pixels. Existing Paint output is reused
only while the Paint presenter remains selected. Clear is the explicit reset.
Paint's toolbar now sets a readable foreground against its light background.

The pre-fix baseline command `DADETO_CHECK_BASE=53ba3aa4a1^ npm run check`
passed all six batches (1,123 suites) and all 11 static gates. This confirmed
that the earlier generator fixture corrections were green in the aggregate,
while also demonstrating the need for the new lifecycle regression test.

Focused fix command: `node scripts/run-jest.js --runInBand test/browser/toys.paint.autoSubmit.test.js test/core/browser/presenters/paint.test.js`:
2 suites / 4 tests passed. Changed-file ESLint passed without warnings.

Final fix validation: `npm run check` exited 0, with all 1,124 unit suites /
11,321 tests passing across six batches and all 11 static gates passing.
`npm run build` also passed. These local results do not establish coverage
