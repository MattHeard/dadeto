## Unexpected hurdle and implementation consequence

A synchronous single-turn JSDOM loop exhausted the fixed512MB heap before
producing a receipt (exit134). Closing windows alone did not release their
WeakRef lifetime during that same event-loop turn. Yielding the real Node event
loop after each closed case fixes it without increasing the heap or dropping
cases. Use the native command below; do not run another simultaneous mutation
worker on this host. A trailing JSON newline encoding was corrected without
changing any evidence fields before the independent protected repeat.

```sh
node --max-old-space-size=512 test/fixtures/typed-logic/heat-pump-presenter-equivalence.js
node --max-old-space-size=512 test/fixtures/typed-logic/heat-pump-presenter-equivalence.js --format-controls
```

Do not eagerly compute every formatted string before the first DOM write: native
format failures currently leave earlier updates visible. Extract actual pure
projection through an ordered lazy sequence (or equivalent) so formatting and
DOM effect order remain unchanged. Keep Intl constructors in a platform adapter;
format ports must delegate each native method access rather than silently cache
a differently observed formatter. Preserve form-value trim/Number semantics and
preset own-key interpretation at typed total boundaries. The source move,
changed-logic coverage/mutation, real artifact closure and exact CI/post-main
evidence remain required; this baseline does not complete the presenter task.
