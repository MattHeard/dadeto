# Atlas native activation replay — 2026-10-20

- **Unexpected hurdle:** The published Pythia config records Transformers 4.40.0, but its Tokenizers 0.19 dependency did not provide a Linux ARM64 CPython 3.13 wheel for this environment. V2 identity records also describe recurrent steps, whereas this model uses token positions.
- **Diagnosis:** The Pythia-14M checkpoint is immutable and only 28,143,920 bytes, so a CPU replay fit the isolated environment. Python 3.13.5 ARM64 was available. PyTorch 2.6.0 has an official CPU wheel for this interpreter; Transformers 4.45.2 with Tokenizers 0.20.3 preserves the GPT-NeoX MLP order while providing compatible wheels. The pinned v4.45.2 implementation applies `dense_h_to_4h`, configured GELU, then `dense_4h_to_h`. Existing V2 activation-position identity is specifically recurrent and cannot represent token positions without conflation.
- **Chosen fix:** Add `src/local/replay_pythia_native_activation.py` with a fully pinned CPU runtime, checkpoint SHA verification, fixed prompt and token IDs, and a pre-hook on `dense_4h_to_h` to capture the post-GELU native MLP vector. It emits 512 stable native-neuron IDs, 512 stable token-position IDs, and two separate input/run-specific observations per position. Experiment identity includes invocation time and procedure revision so later invocations cannot reuse observation IDs. The runner records outputs in a portable research artifact and makes no Neuronpedia calls or writes.
- **Evidence:** Harness commit `5e38062c3b47fa273ceb45efb061c89d819ada49` is pushed to PR #2745. The checkpoint is Pythia-14M revision `94f7c35d5e9f2e9bac8ca839329f505b4d007d5d`; `model.safetensors` SHA-256 is `116a02532db461f91386a5b20f942ff2c8d4de7341e21b55caafc3d7b25f49a1`. The fixed prompt was `The archive holds a quiet map.`; its exact token IDs and the selected last-token index are in the artifact. Replay produced 512 unique components, 512 unique token positions, and 1,024 unique observations. `repeat-1` and `repeat-2` vectors were exactly equal; maximum absolute difference was `0.0`.
