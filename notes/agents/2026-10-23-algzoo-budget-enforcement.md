# AlgZoo pilot in-call budget enforcement

- Unexpected hurdle: the pilot runner recorded token, tool, forward-pass, and elapsed costs only after the opaque investigator adapter returned, so an over-budget call could already have completed.
- Diagnosis: `runInvestigator` had no reservation API or deadline signal. No live provider adapter exists here, so real token accounting and cancellation cannot be claimed from stub behavior.
- Chosen fix: each session now receives an isolated usage reservation ledger and deadline signal. Adapters must reserve token capacity, tool calls, and target-model forward passes before external work, settle reservations with measured use, and honor the abort signal. The runner races the adapter against deadline expiry and records stopped attempts and usage for blinded scoring. Focused regressions use controllable fake deadlines and provider stubs.
