# AlgZoo pilot in-call budget enforcement

- Unexpected hurdle: the pilot runner recorded token, tool, forward-pass, and elapsed costs only after the opaque investigator adapter returned, so an over-budget call could already have completed.
- Diagnosis: `runInvestigator` had no reservation API or deadline signal. No live provider adapter exists here, so real token accounting and cancellation cannot be claimed from stub behavior.
- Chosen fix: each session now receives an isolated usage reservation ledger and deadline signal. Adapters must reserve token capacity, tool calls, and target-model forward passes before external work, settle reservations with measured use, and honor the abort signal. Deadline expiry aborts the request, and budget stops remain in blinded scoring. Ordinary investigator failures also abort and produce a blinded failed-attempt record with only settled costs marked partial, then allow the paired arm to run. Focused regressions use controllable fake deadlines and provider stubs, including independent arm budgets and preservation of earlier attempts.

- Next-time guidance: before enabling a live adapter, reserve exact prompt/context tokens plus maximum generated tokens using the pinned tokenizer, set the provider's output cap to that reservation, settle actual usage, and propagate cancellation to provider, tool, and target-model calls.
