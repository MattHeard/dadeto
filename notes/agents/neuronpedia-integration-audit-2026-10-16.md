# Neuronpedia integration surface audit

Date checked: 2026-10-16

## Verified interface

- Neuronpedia documents a public API for feature/explanation reads, activation tests, graph creation/upload/retrieval, steering, and related tools. Its example feature read is `GET /api/feature/{modelId}/{sourceId}/{index}` and returns feature activations, explanations, logits, and density. Many GETs work without an API key; writes and account-scoped endpoints require `x-api-key`. See [API documentation](https://docs.neuronpedia.org/api-and-data/api) and [account and rate-limit documentation](https://docs.neuronpedia.org/getting-started/accounts).
- Identifiers include model, source, and index. A source can contain SAE features, vectors, or (for some older models) model-native MLP neurons. Attention heads have a separate URL form. Neuronpedia model IDs may differ from Hugging Face IDs. Keep the external model/source/index as a source-specific reference; do not collapse SAE features and native neurons into one untyped identity. See [key concepts](https://docs.neuronpedia.org/getting-started/key-concepts).
- The current [available resources list](https://www.neuronpedia.org/available-resources) includes `circuitgpt-python` MLP sources and `gpt2-small` `*-mlp-oai` sources, but marks the listed ones as not inference-enabled. Direct public reads for `circuitgpt-python/0-mlp/{0,99,100,2047,2048}` returned HTTP 200 and each record returned the requested index. This demonstrates at least 100 addressable IDs; it does not establish replay support.
- Attribution graph API support is documented, including making, uploading, retrieving, and steering graphs. The docs do not establish that this API provides the immutable experiment provenance, held-out evaluation, versioning, or cross-investigator record model required here; DADETO must own those records. See [circuit tracing](https://docs.neuronpedia.org/circuit-tracing/overview).
- Public exports are available as gzipped JSONL organized by model and source, with feature, activation, explanation, model, release, source, and source-set data. Neuronpedia recommends exports rather than per-feature API calls for bulk access. The public bucket is described as unauthenticated. See [exports](https://docs.neuronpedia.org/api-and-data/exports).
- The Neuronpedia code is Apache-2.0, but that is not a blanket license for model weights, SAE artifacts, datasets, or contributed explanations. Its [privacy and terms page](https://www.neuronpedia.org/privacy) describes user-contributed explanations as exportable, but does not provide one general data license for all hosted assets. **Inference:** the registry should preserve an explicit license/source citation per imported asset and allow an asset to be excluded when its reuse rights are unclear.

## Adapter implications and unknowns

- Implement a read-only Neuronpedia adapter first, with bounded pagination/rate handling and a provenance envelope containing the returned model/source/index, retrieval time, and source URL. Use bulk exports for indexing where the source license permits it; use the API for individual reads and permitted live integration checks.
- Store Neuronpedia identifiers as external references, while DADETO owns versioned hypotheses, experiment provenance, predictions, outcomes, negative results, and evidence edges. Never treat a graph or generated explanation as a validated interpretation by itself.
- Before pinning a native-neuron model, fetch a representative MLP-neuron record and establish source cardinality, stable ID/index semantics, available model revision/checkpoint, inference/replay support, and upstream weight/data licenses. The currently visible native MLP resources are not marked inference-enabled, so the spec's replay requirement is not yet demonstrated.
- Before implementing writes to Neuronpedia, verify each intended endpoint and required account key against the live API reference and account permissions. This loop did not submit data or test private write endpoints.
- The browser research tool could not extract the Scalar API reference's endpoint schemas. The live public GET sample was independently verified below; treat the published docs and the captured sample as evidence for that route only, and pin other exact request/response schemas from the reference/OpenAPI before implementing them.

## Live candidate check (2026-10-16)

- `GET https://www.neuronpedia.org/api/feature/circuitgpt-python/0-mlp/0` returned HTTP 200 with `modelId=circuitgpt-python`, `layer=0-mlp`, `index=0`, source/source-set records, and feature data. Requests for indices 0, 99, 100, 2047, and 2048 all returned HTTP 200 with matching indices.
- The feature API's embedded model object reports 8 layers and `neuronsPerLayer=2048`; index 2048 also resolves. This field therefore must not be used as an authoritative exclusive bound without more investigation.
- The public export `v1/circuitgpt-python/0-mlp/source.jsonl` reports `visibility=PUBLIC`, `inferenceEnabled=false`, and `hfRepoId=openai/circuit-sparsity`. Its `model.jsonl` instead reports 8 layers, `neuronsPerLayer=8192`, `visibility=UNLISTED`, and `inferenceEnabled=true`; `sourceset.jsonl` says `visibility=UNLISTED`. These flags conflict with the current Available Resources page and with each other. Prefer observed source-level GET availability for public reads, but keep replay/inference unavailable until the source owner resolves the discrepancy.
- The public Hugging Face model metadata currently resolves `openai/circuit-sparsity` to revision `ebf2603cfe24e5c09e31169d9e34a9fd3d15230c` and declares Apache-2.0. This pins a candidate checkpoint reference, not that Neuronpedia's feature records were generated from exactly this revision. Neuronpedia's source export also names dataset `iamtarun/python_code_instructions_18k_alpaca`; its reuse license and the exact source-to-checkpoint provenance are still unverified.
- Candidate identity for further testing is `(openai/circuit-sparsity@ebf2603cfe24e5c09e31169d9e34a9fd3d15230c, Neuronpedia model=circuitgpt-python, source=0-mlp, index=0..N)`, with index semantics and `N` kept provisional until metadata is reconciled.

## Next experiment

Keep this candidate separate from AlgZoo's independent 16-neuron challenge fixture.
