- [x] The player can reach the upland road from the start and withdraw in range; out-of-range interaction does not withdraw, the unattended crisis settles deterministically to aftermath, and earlier passenger rescue and Latchfolk warning outcomes resolve independently and persist.
- [x] A withdrawn run survives save/export/import, older saves migrate as present, and later world inputs cannot change the settled scene.
- [x] After surge has lost the ferry, a reachable scale −2 locking-pawl interaction repairs a forced-open gate, restores its geometry, lets lower water recede by aftermath, preserves earlier casualties, and survives save/export/import; pre-surge, out-of-range, wrong-scale, intact-gate, and inconsistent repaired-save cases do not create a repair.
- [x] Growth can destroy the signal station; after aftermath, the intact station can file a report, while a destroyed station cannot report but still leaves a reachable upland departure closure. The closure branch, station rubble, and earlier episode outcomes survive save/export/import.
- [x] Keyboard, gamepad, and touch controls expose the interaction used for warning, rescue, withdrawal, repair, and post-storm closure; all five toy docs describe the same control.
- [x] `npm run check` exits 0 with all 10 fast local gates passing and zero clones.

## Pass/Fail Rules

Pass only when every machine-checkable criterion is verified, the user can reach the standalone page, and game actions never use browser wall-clock time. Fail if save/reload loses player or crisis state, or if the frame/control documentation disagrees with runtime behavior.
