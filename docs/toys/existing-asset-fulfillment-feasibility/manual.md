# EXIS1 — Existing Asset Fulfillment Feasibility

Submit an `asset`, a valid normal `proposal`, and its resolved `points` and `spacePoints`. The toy returns `{ "feasible": true }` only when the asset-relevant operations form a coherent world line from stock-in. Delivery return and pickup outbound are runner-only operations and are ignored. The toy is pure: it does not select, assign, persist, or price anything.
