# Dadeto

## Outcome

Make Dadeto a personal software studio and laboratory: a technical platform for turning ideas into useful tools with very little lead time, offering commercial services as secondary income, publishing a portfolio of work and writing, and testing hypotheses about the future of software development.

## Strategic roles

1. **Rapid personal tools:** turn an idea into production-available software in roughly five minutes when the idea fits the platform.
2. **Commercial services:** use the platform to create and operate services that can provide secondary income.
3. **Public work:** use Dadeto as the home for blogging, demonstrations, and a portfolio of work and writing.
4. **Experiments:** use Dadeto as an experimental object for testing hypotheses about how software will be built and operated.

## Relationship to work-in-motion

Dadeto is the umbrella project that gives direction to the other projects. Beads remain the tracker for work-in-motion: each bead should be a bounded current slice that improves the platform, advances a product or service, creates a public artifact, or tests a meaningful hypothesis. The project note holds direction and possible future slices; it is not a queue of beads.

## Decision rule

When evaluating a proposed project or bead, ask which strategic role it serves and what evidence will show that it helped. Work that serves none of the four roles should not enter the active queue without an explicit reason.

## Current question

The direction is now explicit, but the next strategic choice remains open: determine which capability or product slice would most improve Dadeto's ability to produce the other three outcomes.
